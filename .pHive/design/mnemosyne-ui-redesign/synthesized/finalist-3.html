06Operations

Two distinct actions. Reindex shells out against the live Qdrant Cloud store and writes real data. Refresh config cache is purely local — it never touches Qdrant, config.toml, or the graph, and never deletes anything. Neither action, nor anything in this app, can wipe or drop a Qdrant collection.

Reindex

Chunk, embed and upsert the given path(s) into the selected lane's collection (swarm-memory index, default pruning). Requires an explicit lane and at least one path — there is no "reindex everything" option.

Refresh config cache

Clears only this service's in-memory copy of swarm-memory config, so the next load re-reads it fresh. Does not touch Qdrant, config.toml, or the graph — nothing is deleted.

What do these terms mean?
tier
The four fixed levels a persona can sit at, in cascade order: top-orchestrator, company-director, project-orchestrator, code-architect.
scopeId
A human-assigned identity for this persona (a company/project/repo name) — never auto-detected.
Parent(s)
A pointer to where this persona's own content stops and a parent's begins ("query up, never copy down") — the parent's real content is never fetched or shown here, only named.
sourceSummary
What an agent read before proposing a draft — shown when reviewing a draft below. A human-typed draft has no sourceSummary.
