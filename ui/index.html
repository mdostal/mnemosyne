      Operations
      
      
      
        Two distinct actions. Reindex shells out against the live Qdrant
        Cloud store and writes real data. Refresh config cache is purely
        local — it never touches Qdrant, config.toml, or the graph, and never
        deletes anything. Neither action, nor anything in this app, can wipe or drop a
        Qdrant collection.
      
      

      
      
        
      
          
      Reindex
      
          
      
            Chunk, embed and upsert the given path(s) into the selected lane's collection
            (swarm-memory index, default pruning — stale tail chunks of a
            shrunk file are cleaned up; nothing else is touched). Requires an explicit
            lane and at least one path — there is no "reindex everything" option.
          
      
          
      
            
      
              
              
            
      
            
      
              
              
            
      
            
            
      
            
      
          
      
        
      

        
      
          
      Refresh config cache
      
          
      
            Clears only this service's in-memory copy of swarm-memory config,
            so the next load re-reads it fresh. Does not touch Qdrant, config.toml,
            or the graph — nothing is deleted.
